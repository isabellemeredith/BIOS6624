# BIOS6624

Author: Isabelle Meredith

BIOS 6624 was a class focused on realistic data analysis projects for a range of statistical techniques.

Project 0 used linear models to evaluate sleep study recording methods.

Project 1 used both traditional frequentist statistics and Bayesian approaches to modeling to evaluate responses to AIDS treatment based on hard drug use.

Project 2 performed power calculations for a study evaluating the relationship between cognitive decline, amyloid deposition, and inflammatory response.

Project 3 evaluated stroke likelihood using proportional hazard models in the Framingham heart cohort. 

Project 4 simulated data to explore the efficacy, bias, and power of common variable selection methods.
